# One-Page Abstract

## Title

Tariff Policy and Cross-Border Trade: A Province-Destination-Month Difference-in-Differences Study

## Background

Trade policy changes can affect export performance, but simple before-after comparisons are not enough because exports also move with exchange rates, inflation, province-level economic conditions, seasonality, and global demand. This project uses a difference-in-differences framework to compare treated destination markets affected by a tariff-policy event with comparison destination markets before and after the event.

## Data

The intended dataset is a province-destination-month panel of Chinese export values from November 2024 to April 2025. Each observation is a province-destination-month cell. The portfolio version includes a synthetic sample and a data dictionary; real or anonymized data should be placed locally and not uploaded if redistribution is restricted.

## Method

The baseline specification estimates the relationship between export values and a treatment-by-post indicator, controlling for province, destination, and month fixed effects. Controls may include exchange rates, provincial GDP growth, and inflation. The project also includes parallel-trend visualization, placebo checks, and robustness checks.

## Expected Contribution

The project demonstrates applied econometric reasoning rather than only technical regression execution. It shows how to define a credible comparison, structure panel data, interpret fixed-effects DID results, and discuss the limits of causal interpretation in a policy context.
